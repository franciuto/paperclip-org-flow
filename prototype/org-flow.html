Org chart and charactersStructure from GET /api/companies/:id/org. The characters are Paperclip's own: /api/agent-avatars/cap-v1/<palette>/<pose>.png with the poses idle · listening · thinking · working · success · confused · sleepy. If the agent has an uploaded photo, that one is used.
Movement and percentageWorker: ctx.events.on("issue.updated") → ctx.streams.emit("org-flow", …) → UI usePluginStream. Paperclip has no percentage for a single task: the agent reports it through a plugin tool (agent.tools.register, e.g. report_progress) saved with ctx.state, or the ticked checkboxes of the plan document are counted.
